# Lucky One Block - Beat the Ender Dragon (Fabric 1.21.11)

Create a world with World Type = Superflat -> Presets -> "The Void" (structures off), then join.
You spawn on a floating island with ONE Lucky Block. Breaking it gives a random reward or a bad surprise, and it
always comes back. The more you break, the better the loot (tiers).

- End portal (already active) on the WEST side, Nether portal on the EAST side.
- Boss bar "Road to the Dragon": 30% lucky blocks (200), 10% Nether, 15% End, 45% damage to the dragon, 100% = dragon slain.
- Beating the Ender Dragon gives every player in the End: flight, Strength II, Resistance, Regeneration, Speed
  and the Dragon Heart (right-click Dragon Breath, sneak = Dragon Roar, look up = Wing Dash).
- Custom items: Void Saver, Platform Wand, Lucky Wand, Dragon Heart, Super Lucky Block, OP "Skyforged" gear.
- Commands: /luckyisland, /luckyprogress, /dragonheart
